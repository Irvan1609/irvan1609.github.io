Print Skripsi

Halaman ini membantu menyiapkan file skripsi sebelum dicetak. Pilih PDF, cek halaman awal BAB I lewat preview, lalu pisahkan menjadi bagian awal, halaman ganjil, dan halaman genap.

Pisahkan PDF

PDF diproses langsung di browser dan tidak dikirim ke server.
Contoh: 12 berarti BAB I dimulai pada halaman PDF fisik ke-13.
Lihat halaman PDFCek halaman ini sebelum menentukan awal BAB I.
Urutan halaman menggunakan nomor halaman PDF fisik, bukan nomor Romawi/Arab yang tercetak.
Pilih satu file PDF untuk mulai.
Cara pembagian: kalau batasnya 12, File 1 berisi halaman 1-12; File 2 berisi 13, 15, 17, 19, …; dan File 3 berisi 14, 16, 18, 20, …. Hasil pencarian awal BAB I tetap perlu dicek lewat preview sebelum diproses.
