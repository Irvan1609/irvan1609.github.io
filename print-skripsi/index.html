PDF utility

Print Skripsi

Unggah satu PDF skripsi, tentukan halaman terakhir sebelum BAB I Pendahuluan, lalu sistem akan membuat tiga file: bagian awal, halaman ganjil setelah bagian awal, dan halaman genap setelah bagian awal.

Pisahkan PDF

PDF diproses langsung di browser dan tidak dikirim ke server.
Contoh: isi 12 jika BAB I Pendahuluan dimulai pada halaman PDF ke-13.
Urutan halaman menggunakan nomor halaman PDF fisik, bukan nomor Romawi/Arab yang tercetak di dokumen.
Pilih satu file PDF untuk mulai.
Aturan pembagian: jika nilai yang diisi adalah 12, File 1 berisi halaman 1-12; File 2 berisi 13, 15, 17, 19, …; dan File 3 berisi 14, 16, 18, 20, …. Nilai dapat diubah sesuai letak awal BAB I pada skripsi lain.
