Reference workflow

Siapkan referensi untuk Mendeley dengan lebih cepat.

Cari metadata dari DOI atau judul artikel, simpan pustaka sementara di browser, lalu ekspor RIS atau BibTeX. Tidak ada login Mendeley dan tidak ada kredensial akun yang disimpan.

01

Cari metadata

Gunakan DOI untuk hasil paling presisi. Pencarian judul menampilkan beberapa kandidat dari Crossref.

Tambahkan banyak DOI sekaligus

Satu DOI per baris. Maksimal 50 DOI dalam satu proses.

02

Pustaka referensi

Referensi disimpan di localStorage pada browser ini dan tetap tersedia selama data situs tidak dihapus.

Cara masuk ke Mendeley: klik Ekspor RIS untuk Mendeley, lalu di Mendeley Reference Manager pilih Add new → Import library dan pilih file .ris yang diunduh. Jika tidak ada referensi yang dicentang, ekspor menggunakan seluruh pustaka.
