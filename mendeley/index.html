Catatan referensi

Cari dan rapikan referensi yang saya perlukan.

Halaman ini digunakan untuk mencari metadata DOI, menyimpan referensi sementara di browser, lalu mengekspor RIS atau BibTeX untuk Mendeley.

01

Cari referensi

DOI memberikan hasil yang lebih pasti. Jika hanya tersedia judul, halaman ini menampilkan beberapa hasil dari Crossref.

Tambahkan banyak DOI sekaligus

Satu DOI per baris. Maksimal 50 DOI dalam satu proses.

02

Referensi tersimpan

Daftar ini disimpan di browser yang sedang dipakai. Kalau data situs dihapus, daftar ini ikut hilang.

Cara memasukkan ke Mendeley: klik Ekspor RIS untuk Mendeley, lalu di Mendeley Reference Manager pilih Add new → Import library dan pilih file .ris. Kalau tidak ada yang dicentang, semua referensi akan ikut diekspor.
