Cara input data
  1. Excel dengan header: blok seluruh tabel → Ctrl+C → klik sel A1 → Ctrl+V.
  2. Input manual: klik sel → ketik nilai → Enter/Tab untuk berpindah.
  3. CSV: gunakan Import CSV, lalu pilih file dari komputer.
  4. Pastikan setiap kolom hanya berisi satu variabel. Faktor boleh berupa teks/angka; respons harus numerik.
  5. Setelah data benar, pilih Design → RAL untuk menentukan kolom perlakuan dan respons.
Contoh header: Ulangan | Perlakuan | Y. Untuk data tanpa header, gunakan Input Manual atau buat header terlebih dahulu.
